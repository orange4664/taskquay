# 本机目录与 Codex 会话登记

## 操作

1. 打开 `http://127.0.0.1:7676/console/`，使用已有 owner 口令登录。
2. 点击 **添加文件夹**，输入绝对路径或点击文件夹图标，在面板内浏览并选择目录。
3. 核对实际目录和项目名称。目录尚未获准访问时，需要明确勾选授权再登记。
4. 进入项目的 **Codex 会话**，点击 **登记已有会话**。支持搜索、分页、未归档与已归档筛选，每次最多选择 50 个会话。
5. 点击 **登记**。记录保存在“手动登记的会话”中，垃圾桶按钮仅移除 TaskQuay 登记，不删除 Codex 原会话。

若列表为空，先核对所选目录是否就是会话的工作目录；子目录、父目录和其他 worktree 分别匹配。还应确认服务进程使用的 Codex CLI、`CODEX_HOME` 和登录账号。此功能包括桌面端的 `appServer` 会话，但只查询当前本机实例，不发现远程电脑上的会话。会话没有名称时显示短 ID。

## 权限与数据

- 新的浏览、授权、会话查询和登记接口仅允许直接通过本机回环地址登录的 owner 使用，同时检查 Origin 和 CSRF。即使开启远程控制台，这些接口仍拒绝转发请求。
- 文件夹预览有效期为 5 分钟，绑定当前登录。登记前重新核对目录的真实路径、设备和 inode；不会将所选子目录自动提升到 Git 根目录。
- 面板浏览只显示有限数量的可见子目录，跳过文件、符号链接和受保护位置。拒绝通过 GUI 授权整个主目录、文件系统根目录，以及 TaskQuay 状态、SSH 凭据和 Codex 私人会话等受保护位置。
- 会话查询使用 Codex 的状态索引和元数据接口。TaskQuay 丢弃预览正文、turns 和 rollout 路径；提交前核对所选 ID、目录和当前账号实例。不会调用模型、恢复会话、修改 Codex 项目归属或直接编辑 Codex 数据库。
- 导入使用独立引用表，不创建受管代理或执行记录，也不授予归档权限。历史 Token 用量为未知。名称、状态及归档标记是登记时的快照，重新登记可刷新元数据；核验期间发生的归档变化可能要在下一次列表刷新后显示。
- 实例核验用于确认当前本机配置和账号没有切换，不证明每个历史会话由该账号创作。
- 已登录 owner 可以明确扩大文件工具的授权目录。Shell 命令仍以本机用户权限运行，目录检查不构成操作系统沙箱。
- 新授权立即应用于 Web 服务和配置文件。已经运行的独立 agent daemon 保留启动时配置，待其自然空闲退出或完成任务后重启才采用新目录；不要中断正在执行的任务。

## 修复与验证

此维护分支修复控制台路径别名的授权误判、遗漏 `X-Forwarded-Proto` 的本机来源判定，以及登记确认期间的目录替换和登录撤销边界。提供方的原始异常不会直接暴露到登记 API。

依赖覆盖规则放在 `pnpm-workspace.yaml` 中，修复此前放在 npm `overrides` 下而未被当前 pnpm 应用的问题，并更新兼容补丁依赖。2026-09-09 的 `pnpm audit --prod` 从 32 项通告（11 项 high）降至 0 项。这是当日依赖数据库的检查结果，不是对整个项目无漏洞的保证。

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm build
pnpm test
pnpm audit --prod
```

在 macOS 上，系统自动生成的长临时目录可能超过既有 daemon 测试的 Unix socket 路径上限。该环境下使用 `TMPDIR=/private/tmp pnpm test`。

浏览器验收脚本为 `scripts/verify-console-registration.ts`。需要可用的 Google Chrome 和 Playwright；用 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块，再运行 `pnpm exec tsx scripts/verify-console-registration.ts`。脚本使用隔离的临时配置、真实目录浏览和模拟会话数据，覆盖桌面及手机尺寸的登记、搜索、分页、重复提交、移除、持久化和恶意标题转义。

## 升级与回退

本版本追加数据库迁移 14。升级前完成活动任务，停止 Web 服务和 TaskQuay agent daemon，再私下备份完整配置、SQLite 数据及旧版本构建。先在独立源码目录构建和验证，再修改服务启动路径，保留 owner 口令和原有授权目录。

旧程序会拒绝新迁移版本。回退必须停止新服务，同时恢复旧构建和升级前的状态备份，不能仅切换程序路径。备份包含凭据和私人状态，不要提交到 Git 或放进公开目录。
