# 本机目录与 Codex 会话登记

## 添加文件夹和已有会话

1. 打开 `http://127.0.0.1:7676/console/`，使用已有 owner 口令登录。
2. 点击 **添加文件夹**，输入绝对路径或点击文件夹图标，在面板内浏览并选择目录。
3. 核对实际目录和项目名称。目录尚未授权时，先勾选授权，再登记。
4. 进入项目的 **Codex 会话**，点击 **登记已有会话**。支持搜索、分页、未归档与已归档筛选，每次最多选择 50 个会话。
5. 点击 **登记**。记录保存在“手动登记的会话”中，点击垃圾桶按钮可移除登记，Codex 原会话会保留。

列表为空时，先核对所选目录是否与会话的工作目录一致。父目录、子目录和其他 worktree 按各自路径匹配。还应确认服务进程使用的 Codex CLI、`CODEX_HOME` 和登录账号。此功能包括桌面端的 `appServer` 会话，但只查询当前本机实例，不发现远程电脑上的会话。会话没有名称时显示短 ID。

侧栏可按名称或路径搜索项目。切换会话搜索条件或归档状态会清空本次选择；跨分页选择会保留，最多 50 项。任务列表的“加载更多”在自动刷新后保留已加载范围，切换项目或筛选时重新从第一页读取。展开较多页时会降低自动刷新频率；窗口隐藏、对话框打开或阅读指南时暂停轮询。

断线后，当前视图会保留最近一次成功读取的数据，并显示重试入口；切换项目后则重新加载。登录过期或退出时，页面缓存会清空。写入请求超时后，先核对操作结果，系统不会自动重发。

## 权限与数据

- 文件夹浏览、授权、会话查询和登记须在运行服务的电脑上，通过回环地址登录后操作。接口检查 Origin 和 CSRF，并拒绝代理转发；开启远程任务台也不会开放这些登记接口。
- 文件夹预览有效期为 5 分钟，绑定当前登录。登记前重新核对目录的真实路径、设备和 inode；不会将所选子目录自动提升到 Git 根目录。
- 面板浏览只显示有限数量的可见子目录，跳过文件、符号链接和受保护位置。拒绝通过 GUI 授权整个主目录、文件系统根目录，以及 TaskQuay 状态、SSH 凭据和 Codex 私人会话等受保护位置。
- 会话查询使用 Codex 的状态索引和元数据接口。TaskQuay 丢弃预览正文、turns 和 rollout 路径；提交前核对所选 ID、目录和当前账号实例。不会调用模型、恢复会话、修改 Codex 项目归属或直接编辑 Codex 数据库。
- 登记保存的是独立会话引用，不会创建受管代理或执行记录，也不授予归档权限。历史 Token 用量显示为未知。名称、状态及归档标记是登记时的快照，重新登记可刷新元数据；核验期间发生的归档变化可能要在下一次列表刷新后显示。
- 实例核验只确认登记期间的本机配置和账号一致，历史会话的创建账号仍无法据此确定。
- 已登录 owner 可以明确扩大文件工具的授权目录。Shell 命令仍以本机用户权限运行，目录检查不构成操作系统沙箱。
- 新授权立即应用于 Web 服务和配置文件。已经运行的独立 agent daemon 保留启动时配置，待其自然空闲退出或完成任务后重启才采用新目录；不要中断正在执行的任务。

## 修复与验证

此维护分支修复了任务台路径别名的授权误判、本机来源检查遗漏 `X-Forwarded-Proto`，以及登记确认期间目录被替换、登录被撤销时的处理问题。提供方的原始异常不会直接暴露到登记 API。

依赖覆盖规则放在 `pnpm-workspace.yaml` 中，修复此前放在 npm `overrides` 下而未被当前 pnpm 应用的问题，并更新兼容补丁依赖。2026-09-09 的 `pnpm audit --prod` 从 32 项通告（11 项 high）降至 0 项。该结果仅覆盖当日依赖数据库中的已知通告。

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm build
pnpm test
pnpm audit --prod
```

在 macOS 上，系统自动生成的长临时目录可能超过既有 daemon 测试的 Unix socket 路径上限。该环境下使用 `TMPDIR=/private/tmp pnpm test`。

浏览器验收脚本为 `scripts/verify-console-registration.ts`。需要可用的 Google Chrome 和 Playwright；用 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块，再运行 `pnpm exec tsx scripts/verify-console-registration.ts`。脚本使用隔离的临时配置、真实目录浏览和模拟会话数据，覆盖桌面及手机尺寸的登记、搜索、分页、重复提交、移除、持久化和恶意标题转义。

脚本还检查入门页、自动复制和失败后的手动复制、项目搜索、轮询后的任务分页、切换项目时的延迟响应、断线重试和登录过期后的缓存清理。所有截图使用合成项目与会话，不需要实际 ChatGPT 账号或私人配置。

## 升级与回退

本版本追加数据库迁移 14。升级前完成活动任务，停止 Web 服务和 TaskQuay agent daemon，再私下备份完整配置、SQLite 数据及旧版本构建。先在独立源码目录构建和验证，再修改服务启动路径，保留 owner 口令和原有授权目录。

旧程序会拒绝新迁移版本。回退必须停止新服务，同时恢复旧构建和升级前的状态备份，不能仅切换程序路径。备份包含凭据和私人状态，不要提交到 Git 或放进公开目录。
